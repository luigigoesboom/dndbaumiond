# SRD data attribution

`srd/raw/2014/` and `srd/raw/2024/` are unmodified JSON files from
[5e-bits/5e-database](https://github.com/5e-bits/5e-database) (MIT licensed, downloaded 2026-10-07).

The game content in them is taken from:

  Creative Commons Attribution 4.0 International License, https://creativecommons.org/licenses/by/4.0/legalcode
- **System Reference Document 5.2** ("SRD 5.2") by Wizards of the Coast LLC, under the same license.

This project is not affiliated with or endorsed by Wizards of the Coast. The same attribution is shown
in the app footer (`src/App.tsx`).

To refresh the data, re-download the same file names from `src/<ruleset>/en/` in that repository.
Files used: Spells, Levels, Classes, Races + Subraces (2014) / Species + Subspecies (2024),
Backgrounds, Conditions, Languages.
